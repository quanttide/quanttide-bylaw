# 教学实践章程

为规范量潮课堂教学实践活动、明确实践提供方与实训学员的权利义务，制定本章程。本章程适用于内容创作、客户推广、市场调研、活动执行、客服支持、技术协助等各类实训方向，由一份正文与三张附件构成。

本章程所称实践提供方（以下称「提供方」）即量潮课堂运营方；参加教学实践的学员（以下称「学员」）。

## 第一条 性质与适用

1.1 学员参加实训，是提供方课程体系的学习延伸与实践环节，提供方鼓励学员在实训中持续学习、进阶成长。

1.2 本章程所规范的实践为平等主体间的教学实践活动，不构成劳动关系、劳务派遣关系或全职用工关系；学员非提供方员工，不享受提供方员工的工资、社保、公积金、年假、经济补偿等劳动待遇，学员所得为实践津贴或任务报酬，不是工资。

1.3 提供方为实训提供的系统教学、资料、带教、协作账号等基础服务均为免费服务；学员可另行自愿购买提供方平台课程或班课，课程服务与本章程相互独立，另行签订课程服务协议。

## 第二条 实践内容与方式

2.1 实践内容按附件一《项目任务确认单》执行，覆盖内容创作、客户推广、市场调研、活动执行、客服支持、技术协助等方向。

2.2 学员可自主选择是否承接任一任务，提供方不强制派单、不作考勤、不设排班；学员自主安排实践时间与地点，以完成任务交付为目标。

2.3 提供方为学员开通的协作账号（含飞书、企业微信等）仅为沟通与资料共享工具权限，不代表入职，也不代表提供方对学员进行劳动管理；参与终止时账号同步回收。

## 第三条 免费实训服务与学习成长激励

3.1 提供方为学员完成实训任务，免费提供产品知识、业务技能、合规要求、带教答疑等实训服务，不向学员收取培训费、资料费、平台费、带教费、管理费等任何费用，亦不从学员应得报酬中扣除。

3.2 学习激励：提供方对完成实训任务、表现优秀的学员，提供以下激励（可多选、可叠加，具体以附件二《激励规则表》为准）：

- 进阶课程专享优惠价 / 购课抵扣券；
- 实训激励奖金（达标即发，可自由支配，也可自愿用于购课）；
- 优先参与更高阶实训与项目、优先推荐就业机会；
- 实训积分，可兑换课程、活动或权益。

3.3 上述激励为提供方对学员的额外奖励，不影响学员按第四条应得的现金报酬；学员是否领取激励、是否用于购课，由学员自主选择。

3.4 学员购买提供方平台课程或班课的，适用提供方正常课程优惠政策（含老学员优惠、进阶课程包、满赠等），双方另行签署独立课程服务协议；课程费用不视为实训收费，也不抵扣本章程项下任何现金报酬。

3.5 实训学员多从已购买提供方课程的学员中择优选拔进入实训，该选拔系基于学习成果的独立评估与激励加分项，不构成对未购课学生的排除，也不构成对参加实训的收费或变相收费。

## 第四条 报酬与结算

4.1 报酬方式按附件一勾选执行：固定任务津贴、按量计酬、提成 / 佣金或组合方式；计提基数、比例、结算周期、冲回规则以附件及附件三《协作与结算规则》为准。

4.2 已产生的任务报酬以现金支付至学员本人账户，转账备注「实践津贴 / 任务报酬」；提供方不因学员是否购课而扣减或延迟该等现金报酬。劳务报酬个人所得税由提供方依法代扣代缴。

4.3 小额报酬自愿抵扣（可选通道）：对于单笔金额较小、现金支付确有不便的报酬，学员可在结算时自主选择将全部或部分报酬等额抵扣提供方课程或服务费用，具体为：

- （a）提供方结算时主动告知当期应付报酬金额，并提供「现金领取 / 抵扣购课」两种选项，由学员选择；
- （b）学员选择抵扣的，须逐笔书面或线上确认（勾选、签字或系统留痕），未选择的一律按现金发放；
- （c）抵扣金额不低于该笔报酬的现金金额，学员用报酬买课不比直接付现金更贵，并可叠加提供方正常购课优惠；
- （d）抵扣后仍有报酬余额的，余额按现金支付，学员亦可累积至下次抵扣；
- （e）学员随时有权要求改为现金结算，提供方不得拒绝或设置门槛。

4.4 提供方可另行向学员发放实训激励金、购课抵扣券等非现金奖励，该等奖励为额外福利，与本条现金报酬分别核算、分别发放。

## 第五条 安全与风险

5.1 双方确认本章程非劳动关系，提供方不为学员缴纳工伤保险。学员在参与活动中应注意自身安全与合规；如因学员自身原因或第三方原因发生意外，由学员自行处理或向责任方主张。

5.2 学员不得从事高风险、违法或超出约定范围的工作。

## 第六条 保密与知识产权

6.1 除经提供方明确公开、或双方另行约定的开源 / 分享内容外，学员对实训期间知悉的提供方未公开的商业秘密、客户信息、技术资料、教学材料负保密义务；保密期限至该等信息被提供方公开或进入公知领域之日止。提供方发起的开源活动、公开分享等内容，其使用与传播规则以对应活动约定为准，不受本条限制。

6.2 学员在实训期间，基于提供方提供的思路、方法、教学、资源、数据或带教，为完成实训任务所参与产生的全部交付成果与知识产权（含著作权、专利申请权、商业秘密等）归提供方所有，学员享有署名权。双方确认：提供方提供的系统教学、带教与资源投入，构成学员参与上述成果的对价；学员以参与实训换取学习成长与本章程项下报酬，成果权属归提供方系双方对价安排，提供方可自行决定该等成果的使用、修改、商业化或开源。学员于实训前已持有的既有成果、或与实训任务无关的独立创作，权利仍归学员所有。

## 第七条 参与期限与终止

7.1 本章程自学员参加教学实践之日起适用，至实践关系依本条终止时止；参与可延续，不设固定届满日。

7.2 任何一方提前 __ 日书面通知对方即可终止实践关系。

7.3 学员丧失在校学生身份（毕业、结业、退学、开除等）时，应于三个工作日内书面通知提供方。自该情形发生之日起，实践关系自动终止。双方可于同期另行签署《推广服务合作协议》，将原实训关系转为平等民事主体间的劳务 / 承揽合作关系继续履行，学员已产生未结算报酬依 7.4 结清；未另行签约的，本章程即行终止，账号、资料同步回收。转换后的合作性质、报酬、结算与合规要求，以《推广服务合作协议》约定为准。

7.4 实践关系终止时，已产生未结算的现金报酬按第四条无条件结清，账号、资料、客户线索同步交接；学员已购买但尚未消费完毕的付费课程，按独立课程服务协议处理，不受本章程终止影响。

### 转换后的合作规则

1. 转换后为劳务 / 承揽合作，非劳动关系：学员自主接单、自主安排时间地点，提供方不考勤、不排班、不设固定月薪；
2. 报酬按成果 / 任务结算，禁止性红线延续——不从已赚报酬扣费用、不以购课为条件克扣已赚分成、小额可自愿等额抵扣购课（沿用第 4.2、4.3 条精神）；
3. 个税由提供方依法代扣代缴，转账备注「劳务报酬 / 推广佣金」，业务合同、工作记录、支付凭证三类证据留存至少 3 年；
4. 激励政策可继续适用（进阶优惠、奖金、积分等），做成叠加福利而非门槛。

## 第八条 附则

8.1 本章程附件一《项目任务确认单》、附件二《激励规则表》、附件三《协作与结算规则》与本章程具有同等效力；换方向、换产品、调激励力度只改附件，正文不随之重签。

8.2 本章程未尽事宜，双方另行书面约定；争议协商解决，协商不成提交提供方所在地人民法院诉讼。

8.3 本章程自发布之日起施行。
